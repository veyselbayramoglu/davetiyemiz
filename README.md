# Zeyneb & Veysel Dijital Davetiye

## GitHub Pages ile yayınlama

1. GitHub'da yeni ve herkese açık bir depo oluşturun.
2. Bu klasördeki tüm dosyaları deponun ana dizinine yükleyin.
3. Repository > Settings > Pages bölümüne gidin.
4. Source kısmında `Deploy from a branch` seçin.
5. Branch olarak `main`, klasör olarak `/root` seçip kaydedin.
6. Birkaç dakika sonra GitHub size paylaşılabilir bağlantıyı gösterecektir.

Örnek:
https://kullaniciadi.github.io/depo-adi/

## Dosyalar

- `index.html`: sayfa yapısı
- `style.css`: mobil uyumlu tasarım ve animasyonlar
- `script.js`: kapak açılışı, paylaşım, takvim ve geçişler
- `assets/`: davetiye görselleri ve sosyal medya önizlemesi
